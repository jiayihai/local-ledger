## 目录

- `android/`：实际安卓工程、核心规则与设备测试。
- `tools/build-android.ps1`：当前电脑的便携式工具链构建入口。
- `docs/`：需求、设计、计划和阶段证据；网页原型不是安卓运行截图。
- `outputs/releases/`：阶段安装包。
- `.tools/`：本机工具和缓存，未纳入源码版本管理。
- `work/`、`output/`：需求原型制作与检查材料。
