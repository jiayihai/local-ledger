# 本地记账 App · 需求讨论稿 v0.1

状态：历史讨论版本；账本结构和记账流程已由《需求讨论稿-v0.2.md》替代。保留本文件仅用于追溯早期候选方案。

## 1. 用户已明确的信息

- 设备：安卓手机，小米 14；需要能安装在手机上。
- 核心用途：记录支出与收入。
- 自建大分类，例如“个人”“恋爱”；每个大分类内可以自建小分类，例如“饮食”“娱乐”“会员”。
- 统一记账入口；输入记录后，在底部弹出分类选择。这里“记录完成”指输入完成还是保存完成，待确认。
- 大分类集中在一个页面，以长方形卡片纵向排列。
- 支出使用黑色边框，收入使用红色边框；边框作用于大类还是明细，待确认。
- 可导出固定格式 Excel，服务于后续分析。
- 数据存在手机本地；当前不考虑跨设备共享。
- 风格：苹果式简洁、圆润、有层次；黑白红，不增加其他彩色；希望启动快。
- 先讨论并确认需求，再进入标准软件开发流程；用 SVG 帮助选择。

## 2. 术语与结构候选（尚未定案）

建议把“个人、恋爱”称为“账本”，把“饮食、娱乐、会员”称为“分类”，一笔收入或支出称为“记录”。

### 混合账本

个人账本 / 恋爱账本 → 收支类型 → 对应的小分类 → 记录。

每个账本都能记收入与支出。卡片内部的支出区域黑框、收入区域红框，账本外框用中性灰度边界。明细也可以按收支使用黑框或红框。适合同一生活场景统一查看收支。

### 收支分账

个人支出 / 恋爱支出 / 个人收入 → 小分类 → 记录。

建账本时确定收支类型。整个支出账本黑框、收入账本红框。适合希望整张账本卡片都以边框区分收支的安排；同一场景有两种收支时需要两个账本。

两种结构都支持自定义名称、统一入口。图中数据均为示例。

## 3. 推荐记账流程（待确认）

打开 App → 唯一“记一笔”入口 → 选择支出/收入并输入金额 → 底部选择账本和小分类 → 保存。

- 默认支出；账本、分类的默认值规则在下一轮确认，原型只展示“个人 / 饮食”。
- 日期默认今天，允许补记；备注可选。
- 按账本和收支类型展示小分类，常用分类优先的具体规则待讨论。
- 账本、分类、金额确认后再形成正式记录。
- 退出未完成输入时可保留草稿；是否需要草稿待确认。
- 如果用户想要“先保存，再补分类”，需要另外明确未分类记录、取消选择与统计归属的规则。
- 原型用于讨论流程，示例数据不代表手机数据库，也不模拟真实导出。

## 4. 首版范围建议（不等于已确认）

| 范围 | 建议行为 |
| --- | --- |
| 账本 | 新建、改名、排序、归档；删除时历史记录如何处理需单独确认 |
| 分类 | 每个账本自行创建和改名，收入与支出分类分开；停用后保留历史记录 |
| 记账 | 金额、收支类型、账本、小类、日期、可选备注 |
| 明细 | 查看、编辑、删除；按日期、账本、收支类型筛选 |
| 基础合计 | 本月收入、本月支出、收支结余；“结余”不称为银行卡余额 |
| 导出 | 导出全部或指定日期范围、指定账本的标准 .xlsx 文件 |
| 本地存储 | 无需账户；离线完成核心操作；具体数据存储和安装方式在需求确认后选择 |
| 备份恢复 | 建议讨论手机本地备份与恢复；Excel 导出不等于完整备份 |

首版建议暂不加入：云同步、共同记账、支付平台自动导入、银行卡余额管理、预算提醒、复杂分析图表、AI 分类、订阅自动扣费。用户尚未决定这些功能。

## 5. Excel 草案（待确认）

- 格式：.xlsx；主工作表名“收支明细”；一笔记录一行；列名、顺序和含义固定；不合并明细单元格。
- 建议列：记录ID、发生时间、收支类型、账本ID、账本名称、分类ID、分类名称、金额、币种、备注、创建时间、更新时间。
- 金额导出为可计算的数值，最多两位小数；金额存正值，通过收支类型区分，不把“¥”写入金额文本。
- 首版建议只支持人民币，币种固定 CNY；保留币种列用于解释数据，不意味着支持多币种记账。
- ID 便于识别同一笔记录、同一账本和分类；改名后导出使用当前名称还是历史名称需要确认。
- 日期按手机本地时间解释；时间列的 Excel 类型与展示格式在后续导出规范确认。
- 可增加“导出说明”工作表，记录模板版本、导出时间与筛选范围。
- 是否附带汇总表、需要哪些附加列，留待专门一轮讨论。

## 6. 视觉方向（待选择）

- 明亮底色、黑色主文字、红色收入强调；灰度仅用于白与黑之间的层次，不增加彩色装饰。
- 圆角矩形纵向排布；使用字号、留白、细分隔、低强度阴影建立层次。
- 收支同时带“支出 / 收入”文字和金额符号，不只依赖颜色。
- 两种结构共用整体视觉语气；结构选定后再比较留白、边框粗细、卡片密度等视觉细节。
- 暂不照搬 iPhone 的系统外观或刘海；最终适配小米 14 的系统栏与操作习惯。
- “快速启动”后续需要明确冷启动、是否直接打开记账页及真机验收标准，暂不承诺未经验证的时间指标。
