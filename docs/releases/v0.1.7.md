# 本地记账 0.1.7 · 流水与 Excel 导出

「明细」现在可以按周、月、年或自定义日期范围看流水，并把筛选后的记录导出为本地 Excel。本次发布也包含 0.1.3 之后的日历更新。

## 本次更新

- 流水总览分别显示总开销和总收入。可点大类查看小类，再点小类看逐笔流水，记录仍能编辑。
- 导出使用当前日期范围和分类，保留原来的「收支明细」「导出说明」两张工作表及 11 列结构。
- 日历采用紧凑布局，支持左右滑动翻月、按日查看记录和每日消费基线。点左上日期可用三行滚轮或直接输入年月日。
