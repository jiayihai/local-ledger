# 本地记账 0.1.3 · 阶段体验版

原生 Android 本地记账工具，最低支持 Android 8.0。本版本为开发阶段体验包，建议使用测试账目验收。

## 本次更新

- 明细记录可以点开修改金额、日期、备注和所属大类、小类；保存更新原账目，汇总随之重算。
- 分类管理增加大类改名，历史名称同步更新，记录和排列顺序保留。
- 延续 0.1.2 的大类长按拖动排序、小类改名/删除/停用、选项自动换行。

## 安装

下载附件 `local-ledger-0.1.3-debug.apk`，在 Android 手机上按系统提示安装。

已有本项目 0.1.x 体验版时，直接覆盖安装，请勿先卸载；卸载会清除本地账目。本包包名 `cn.localledger.app.debug`，使用阶段调试签名。

## 验证与当前限制

- APK 构建与签名校验通过，8 项核心 JVM 测试通过，Android Lint 0 错误。
- 12 项数据库设备测试已编译，尚未连接设备执行。真机运行、升级和界面交互仍待验收。
- Excel 导出与本地备份恢复的手机界面尚未交付。
- 筛选、小类排序、记录删除撤销，以及支付通知辅助记账尚未交付。
- 现有版本未配置联网权限，账目存储在手机本地。
