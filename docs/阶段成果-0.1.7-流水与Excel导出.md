# 0.1.7 流水与 Excel 导出

- 「明细」的「列表」改为「流水」。默认本月；周按周一至周日，月和年按自然月、自然年。可用箭头前后切换或点标题选日期定位；自定义区间包含开始日和结束日。
- 总览先显示总开销和总收入，再分别列出有记录的大类；点大类可看各小类的金额、笔数和逐笔记录；点小类可只看该小类。逐笔记录仍可点击修改。
- 「导出 Excel」导出当前区间。如果已进入大类或小类，则只导出该分类。使用安卓本地文件选择器选位置，默认文件名包含起止日期；不需要授予整个存储空间的访问权限。
- Excel 保留原来固定的「收支明细」和「导出说明」两张工作表及 11 列结构。「导出说明」会标明日期区间和分类范围。已停用分类的历史记录照常统计，已删除记录不计入。
