# 明细页：日历与每日消费基线

状态：已确认，随 App 0.1.4 交付。SVG 中的金额与记录均为示例。

0.1.5 采用[紧凑方案 B](design/details-calendar-compact-options.svg)：整月仍可见，无收支的周约 44 dp，有收支时按行内内容扩展；日期统一用 15 sp 常规字重，金额字号保留，基线设置收为一行。

0.1.6 实现[已确认的翻月和日期选择交互](design/details-calendar-gestures.html)：在日期网格左滑到下个月、右滑到上个月；点左上完整日期打开居中弹窗，年、月、日各显示三行，可滑动或点击中间数字原位输入，点「跳转」同步选中日期和当天明细。

## 页面与交互

1. 底部点「明细」默认看到日历，初次进入选中今天。左右箭头切换月份，回到当前月选今天，其他月份先选 1 日；「今天」可从任意月份跳回今天。保留「列表」切换，首页各大类的「明细」仍打开对应大类的列表。
2. 日历固定七列，周日开头，按实际月份排 4–6 行。日期下方分行显示当日支出总额和收入总额，支出黑字加 `−`，收入红字加 `+`；对应方向无记录时不显示金额。邻月日期淡显，只用于补齐网格。窄屏上金额过长时，格内可缩写，下方的当日汇总和记录始终显示完整金额。
3. 日历下方显示「每日消费基线」。点金额编辑，支持元和分；首次未设置时不标深，设置后全账本各月份共用一个基线，保存在本机。可清除设置以关闭标记。按当日支出总额判断，**严格大于**基线才把日期底色标深，收入不抵扣。各格金额继续显示在白底上；选中的日期另外加外框。示例：设为 ¥50.00，支出 ¥50.00 不标深，¥50.70 标深。
4. 选一天后，下方显示日期、当日收支汇总和当日记录，按发生时间从晚到早排列。当天没有记录时显示「这天还没有记录」。点击任一记录复用现有编辑页，可改金额、日期、备注、大类和小类。保存后保留所选日期，重算受影响的日期；如果把记录移到另一天，它会从原日列表移到新日。

## 实现顺序与验收

1. 按交易发生日期汇总收入和支出，使用整数分计算。停用分类的历史记录仍参与汇总，已删除记录不计入。
2. 接入日历、列表切换及基线本地设置。沿用现有账单数据结构，无需迁移数据库；日历取数范围是整个账本，大类列表保留原筛选逻辑。
3. 接回原有记录编辑流程。验证月份首尾和六周布局、¥50.00 与 ¥50.01 边界、同日收入不抵扣、重新启动仍保留基线、编辑后汇总刷新、窄屏金额不重叠，并提供新版 APK 供真机验收。
