# 0.1.1 大类管理更新

2026-11-17，针对“大类如何删除”的反馈补充管理入口。本次为大类管理的增量交付，不代表 M2 全部完成。

## 安装与操作

安装包：[0.1.1 APK](../outputs/releases/0.1.1/local-ledger-0.1.1-debug.apk)。请覆盖安装旧版，不要先卸载；卸载会清除本地账目。本版包名与调试签名和 0.1.0 相同，版本号已递增，数据库结构未变。实际设备升级仍待验证。

1. 打开底部“设置”，进入“分类管理”。
2. 没有任何历史记录的大类：点“删除”，确认后删除大类及其小类；该操作无法撤销。
3. 已有历史记录的大类：点“停用”，确认后从记账首页隐藏，历史明细与汇总保留。
4. 停用的大类仍在分类管理内，点“重新启用”即可恢复首页入口，小类原有状态保留。

有历史记录时不显示删除按钮，数据库层也会拒绝直接删除，以保护历史账目。此规则将未来软删除的记录也计入历史。

## 验收步骤

- 创建一个测试大类并添加小类，尚不记账时删除，检查大类与其小类一起消失。
- 另建测试大类并记一笔账，检查分类管理只有停用入口，没有删除入口。
- 停用后首页入口消失，明细及本月累计保持原值；重新启用后入口恢复。
- 关闭并重开 App，检查结果保留。
