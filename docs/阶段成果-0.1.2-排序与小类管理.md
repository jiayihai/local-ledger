## 操作与行为

- 大类排序：在“记账”首页长按大类卡片，上下拖动，松手保存。卡片跟随手指移动，靠近列表顶部或底部会自动滚动；取消手势放弃当前调整。普通点按仍进入记账。分类管理与首页采用相同的已保存顺序；停用大类不参与首页拖动，重新启用时保留其原槽位。
- 小类管理：“设置 → 分类管理 → 对应大类的管理小类”。可改名、删除无历史记录的小类，或停用/重新启用。改名保留分类 ID，历史明细使用新名称；同一大类内不能重名，不同大类可同名。
- 已有历史记录的小类保持“停用”规则，隐藏记账选项并保留历史及累计。无历史记录时可确认删除，无法撤销。所属大类停用期间，需先启用大类，才能重新启用小类。
- 选择小类的弹层按按钮实际宽度自动换行，不再每行固定三个。常规按钮最小高度 48 dp，横向和纵向间距各 8 dp；名称超过整行宽度时在按钮内换行。选项较多时弹层内容可上下滚动，保留新建入口。
- 分类管理的操作按钮也允许自动换行，减少窄屏或大字体时的挤压。

## 真机验收清单

1. 新建至少三个大类，上下拖动调整，确认顺序；重开 App 再检查保存结果。顺带检查普通点击、长按拖动后松手不会误开记账页。
2. 新建足够多的大类，使列表超出一屏，长按并移到列表边缘，检查自动滚动和跨屏排序。
3. 停用一个大类，再调整其余大类顺序；重新启用后检查顺序及账目均完整。
4. 给两个大类分别创建同名小类：可以保存。在同一大类下改成已有名称：应拒绝，原数据保持。
5. 将有记录的小类改名，检查明细名称更新、金额与条数不变；停用后选项隐藏、累计不变，重新启用后恢复。
6. 删除无记录的小类，检查其余小类保留；再新建一个小类，检查它出现在最后。
7. 使用截图中的名称“吃饭”“衣服，护肤，变帅”“ai会员，梯子”，检查放不下的按钮整体移到下一行。再检查长名称、大字体、多选项滚动。
