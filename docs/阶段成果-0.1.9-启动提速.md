# 0.1.9 启动提速

- 启动从 Room 读取分类，以及由 SQLite 一次计算的本月各大类合计；不会把全部账目逐笔加载到首页。首页总收支和卡片金额来自同一次读取。
- 打开明细后，日历读取当前月和相邻月份，流水读取所选日期范围；汇总在后台完成。分类管理另查历史笔数。新增、修改、删除和撤销会刷新汇总并使旧的区间结果失效。
- 数据库仍使用原结构和已有的日期索引。停用分类的旧账照常统计，已删除账目不计入收支；分类管理仍尊重原有历史保护。
- App 增加首页可用时的完全绘制标记。比较启动耗时须在同一台手机和同一份账本上进行，记录首帧与首页可用时间；本机 SQLite 查询验证不代表真机启动耗时。
